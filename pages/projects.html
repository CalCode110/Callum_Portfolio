Individual Project COMP710 C++ · SDL2 · FMOD · OpenGL

Rally Apex Hunter

A top-down 2D rally racing game built entirely in C++ using SDL2 for rendering, FMOD for spatial audio, and Box2D for physics. Developed over a semester as my COMP710 individual project from Gold milestone through to submission.

The game features a full AI opponent system using waypoint pathfinding, border avoidance logic, and an unstuck mechanism to handle edge cases when the AI gets trapped. Player feedback is handled through a HUD showing speed, lap times, and a star rating system on completion.

Key Features

  • Waypoint-based AI with border avoidance and unstuck system
  • FMOD spatial audio — engine pitch tied to vehicle speed
  • Box2D physics integration for vehicle handling
  • Particle effects, fullscreen mode, Xbox controller support
  • Data-driven design — game data loaded from external files
  • AUT/FMOD splash screens, instructions screen, cheat codes

Documentation Produced

  • Game Pitch Document (1-page non-technical)
  • Game Design Document (multi-page with diagrams and asset list)
  • Technical Design Document (UML, flowcharts, acceptance test plan)
  • Post-Mortem (1250+ words across five sections)
  • GitHub commit log and readme.pdf

Reflection

The hardest parts of this project were setting up the game programming framework from scratch and getting the car physics to behave realistically. Working through those challenges was frustrating at times but incredibly rewarding — by the end I had a solid understanding of how a game engine actually works under the hood. I'm most proud of the fact that I built something I would genuinely have played on a flash game website as a kid. If I were to build it again I'd invest more time into the AI system — it works well most of the time, but there are edge cases I'd love to iron out.

Group Project COMP710 C++ · SDL2 · Tiled · Photopea

Dungeon Descent

A top-down dungeon shooter developed as the COMP710 group project, inspired by Doom and Enter the Gungeon. The team worked in a Scrum-based workflow with sprint cards, a product backlog, and MS Planner scheduling.

My primary contributions were documentation and visual assets. I designed and produced room backgrounds in Tiled, sourced and refined sprites in Photopea to keep the game's aesthetic consistent, and authored both the Game Pitch Document and the full Game Design Document.

My Contributions

  • Game Pitch Document and Game Design Document
  • Room background design and layout using Tiled
  • Sprite sourcing and refinement in Photopea
  • Git repository management and version control
  • Scrum sprint planning and backlog management

Reflection

Working on Dungeon Descent with my group was a great experience — collaborative development was new territory for me after only building games solo. My biggest contribution beyond the obvious was keeping the visual direction cohesive; finding sprites that actually looked good together took more effort than expected but made a real difference to the final product. Like most group projects we cut it fine with the submission deadline, but we shipped a complete version we're proud of. The experience taught me a lot about communication and how to divide work effectively across a team.

Solo Project C COMP612 · Semester 2, 2025

Helicopter Game

A side-scrolling helicopter game built in C as part of COMP612 — Computer Graphics Programming. The player navigates through obstacles using precise vertical thrust control, with lift and gravity working against each other throughout.

Key Features

  • Side-scrolling gameplay with obstacle avoidance
  • Helicopter physics — lift and gravity simulation
  • Collision detection system
  • Score tracking and high score system

Reflection

This project came out of COMP612 in Semester 2, 2025 — one of the most enjoyable papers I've taken. I finished with 100% across the paper and the lecturer asked to use my project as an example for future students, which was a highlight of my degree so far. Building this gave me a proper foundation in GUI game programming that I carried directly into C++ work. Looking back now there's a clear jump in complexity between what I built here and what I can do in COMP710 — but this project is where that journey started.

Solo Project Java Semester 1, 2025

Blackjack

A fully implemented Blackjack game built in Java — my first real game project. After an early console version that was rough around the edges, I committed to building a polished GUI version with a proper database backend.

Key Features

  • Full deck management — shuffling and dealing
  • Ace value logic (1 or 11 depending on hand)
  • Betting system with chip tracking
  • Dealer AI following standard Blackjack rules (hit on <17)
  • Derby database — stores player names and chip balances across sessions
  • Win, lose, bust, and push detection

Reflection

This was my first game — built in Semester 1, 2025, just before the helicopter project. Using Java was interesting knowing that games like Minecraft and RuneScape were built with it. The console version I initially submitted was unpolished, which motivated me to go further and build a full GUI version complete with a Derby database to persist player names and chip counts between sessions — basically a real casino, except you don't lose actual money. The experience of going back and improving something from scratch was a valuable lesson in what polish actually takes.
