Individual Project COMP710 C++ · SDL2 · FMOD · OpenGL

Rally Apex Hunter

A top-down 2D rally racing game built entirely in C++ using SDL2 for rendering, FMOD for spatial audio, and Box2D for physics. Developed over a semester as my COMP710 individual project from Gold milestone through to submission.

The game features a full AI opponent system using waypoint pathfinding, border avoidance logic, and an unstuck mechanism to handle edge cases when the AI gets trapped. Player feedback was handled through a HUD showing speed, lap times, and a star rating system on completion.

Key Features

  • Waypoint-based AI with border avoidance and unstuck system
  • FMOD spatial audio — engine pitch tied to vehicle speed
  • Box2D physics integration for vehicle handling
  • Particle effects, fullscreen mode, Xbox controller support
  • Data-driven design — game data loaded from external files
  • AUT/FMOD splash screens, instructions screen, cheat codes

Documentation Produced

  • Game Pitch Document (1-page non-technical)
  • Game Design Document (multi-page with diagrams and asset list)
  • Technical Design Document (UML, flowcharts, acceptance test plan)
  • Post-Mortem (1250+ words across five sections)
  • GitHub commit log and readme.pdf

Group Project COMP710 C++ · SDL2 · Tiled · Photopea

Cryptfire

A top-down dungeon shooter developed as the COMP710 group project, inspired by Doom and Enter the Gungeon. The team used a Scrum-based workflow with sprint cards, a product backlog, and MS Planner scheduling.

My primary contributions were documentation and visual assets. I designed and produced room backgrounds in Tiled, combined and refined sprite layers in Photopea, and authored the Game Pitch Document and the full Game Design Document for the project.

My Contributions

  • Game Pitch Document and Game Design Document
  • Room background design and layout using Tiled
  • Sprite layer combining and refinement in Photopea
  • Git repository management and version control
  • Scrum sprint planning and backlog management

Solo Project C++

Blackjack

A fully implemented Blackjack game built in C++, covering the complete card game logic from deck shuffling and hand evaluation through to a betting system and win/loss tracking across multiple rounds.

Key Features

  • Full deck management — shuffling and dealing
  • Ace value logic (1 or 11 depending on hand)
  • Betting system with chip tracking
  • Dealer AI following standard Blackjack rules (hit on <17)
  • Win, lose, bust, and push detection
